# Sivabalan — Personal Portfolio

A modern, high-performance personal portfolio built with Next.js 15, React 19, TypeScript, and vanilla CSS with creative ASCII shaders, smooth Lenis scrolling, and responsive editorial layout.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```

## 🛠️ Personalization

All personal details, project data, skills, work experience, and contact links are centralized in:
`src/data/portfolioData.ts`

- **Name, Role, Bio & Links**: Update `personalInfo`
- **Featured Projects**: Update `projects`
- **Technical Skills**: Update `skillCategories` and `constellationSkills`
- **Work Experience**: Update `experienceList`
- **Education**: Update `educationList`

## 🎨 Tech Stack
- **Framework**: Next.js 15 (App Router), React 19, TypeScript
- **Styling**: Modular CSS & Design Tokens
- **Interactivity**: Framer Motion, Lenis Smooth Scroll, Canvas ASCII Shaders
- **Deployment**: Vercel / Cloudflare / Node.js
